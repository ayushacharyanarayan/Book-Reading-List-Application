# Book Reading List Application

An app for adding books, managing reading status, filtering books, deleting entries
and viewing summary counts. Built with HTML, CSS and JavaScript (no libraries).

## Features
- Add a book with title, author and status (To Read / Reading / Finished)
- Change the status of any book from its dropdown
- Filter the list: All, To Read, Reading, Finished
- Delete books
- Summary counts: Total, To Read, Reading, Finished
- Form validation and duplicate check
- Data saved in the browser (localStorage), so the list stays after refresh
- Responsive layout with automatic dark mode

## How to run
Open `index.html` in any browser. No installation needed.

## Deploy for free (live demo)
Upload the folder to GitHub, then import the repo on vercel.com or netlify.com.
